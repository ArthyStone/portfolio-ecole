Profil

J'ai toujours aimé la programmation,
j'ai développé mes compétences en autodidacte autour des langages html css js et node.js ainsi que php.

Pour le moment, j'utilise peu de librairies (hors node.js) je code la plupart du temps en from scratch, en vanilla.
Exemples: en PHP, j'ai préféré apprendre à faire un routeur moi-même que d'utiliser Laravel ou Symfony,
je fais le css de mes sites web moi-même, sans react.

Je compte me former sous peu à Symfony et à React,
compétences que j'ai volontairement ignoré pour d'abord me créer des bases solides.
En dehors de tout ça, j'ai des compétences qui collent à ce que je fais,
je maîtrise SQL et je consolide actuellement le dialecte de PgSQL ainsi que la programmation en PLpgSQL,
je maîtrise aussi mongodb et je consolide également mes compétences en git CLI.

Je recherche une alternance dans le domaine informatique, il est évident que le poste de développeur en tant qu'alternant n'est maintenant qu'une légende urbaine, c'est pourquoi je me dirige actuellement vers les postes de support.
